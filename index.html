How the Internet
Was Born

It began as a research project to share scarce computers between universities. Over four decades, a handful of ideas—packet switching, open protocols and hypertext—grew into a network that connects billions of people.

    Key Ideas

    Four inventions that turned a few linked computers into a global network.

    01

    Packet switching

    Instead of reserving a whole line for one call, messages are chopped into small packets that travel independently and are reassembled at the destination. The network stays useful even when parts of it fail.

    A
    B
    02

    TCP/IP

    IP gives every machine an address and moves packets between networks. TCP sits on top, checking that every packet arrives, in order, and asking for any lost ones again. Together they let any network talk to any other.

    03

    Domain Name System

    People remember names, computers use numbers. DNS, introduced in 1983, translates names like example.com into IP addresses through a distributed, hierarchical directory.

    example.com 192.0.2.10
    04

    Hypertext & the Web

    The World Wide Web is an application that runs on the Internet. It combines URLs, the HTTP protocol and HTML pages so that any document can link to any other with a single click.
